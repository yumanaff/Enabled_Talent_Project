# Manual test pages

Two small pages for testing Ease by hand. They work offline.

- `test-page.html`: moving things, a pop-up after 3 seconds, a cookie banner, fake pressure messages and a
  countdown, risky links, a form, icon-only buttons and a long article.
- `scam-page.html`: a FAKE "your computer is infected" page. Ease should show a scam warning at the top.

## How to open them

1. Go to `chrome://extensions`, click **Details** under Ease, and turn on **Allow access to file URLs**.
2. Drag the file into a Chrome window (or press Ctrl+O / Cmd+O and pick it).

`Ease test sheet.xlsx` is the team scorecard: Summary (fills itself in) and Sites (every feature on every site, plus other features).
